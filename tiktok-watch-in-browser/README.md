To be used with [Violentmonkey](https://violentmonkey.github.io/) or another userscript manager.

## Features

Allows you to watch a TikTok video in the browser, without downloading the app.

## Installation

Just [click here](https://github.com/danielvigaru/userscripts/raw/main/tiktok-watch-in-browser/tiktok-watch-in-browser.user.js) or select `Install from URL` and use the direct link to the script `https://github.com/danielvigaru/userscripts/raw/main/tiktok-watch-in-browser/tiktok-watch-in-browser.user.js`.
